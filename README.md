# Bank Loan & Credit-Debit Analytics Dashboard

End-to-end data analytics project analyzing a 65,535-record loan portfolio 
and a 100,000-record transaction dataset, built across Excel, SQL, Tableau, 
and Power BI.

## Project Overview
This project implements 30+ KPIs covering loan performance, credit risk, 
and transaction behavior for a bank, using a full BI toolchain from raw 
data to interactive dashboards.

## Tools Used
- **Excel** — Pivot tables, SUMIFS/COUNTIFS, dynamic slicers, KPI cards
- **MySQL** — Aggregate queries, CASE statements, GROUP BY, risk flagging
- **Tableau** — Interactive cross-filtering dashboards, relational data models
- **Power BI** — DAX measures, drill-throughs, slicers

## Key KPIs Delivered
- Total Loan Amount Funded, Total Loans, Total Collection, Total Interest
- Default Rate, Delinquency Rate, Branch-Wise Revenue
- Total Credit/Debit Amount, Credit-to-Debit Ratio, Account Activity Ratio
- High-Risk Transaction Flag (95th percentile threshold)
- Branch Transaction Growth, Transaction Method Distribution

## Folder Structure
- `/Excel` — Excel dashboards for loan and transaction KPIs
- `/SQL` — MySQL queries used to validate and compute all KPIs
- `/Tableau` — Tableau packaged workbooks (.twbx)
- `/PowerBI` — Power BI report file (.pbix)
- `/Presentation` — Final project presentation deck

## Key Results
- Total Loans Funded: ₹732.70M
- Total Collection: ₹814.90M
- Default Rate: 1.56% | Delinquency Rate: 10.84%
- Total Credit: ₹127.60M | Total Debit: ₹127.29M
- ~5,000 high-risk transactions identified out of 100,000
